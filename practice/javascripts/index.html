console.log(5 + 3); console.log("5" + 3); console.log(5 + "3"); console.log("5" - 3); console.log("5" * 3); Output: 8 53 53 2 15 Samajh bhai: 5 + 3 → dono numbers, isliye addition. "5" + 3 → ek string hai, isliye concatenation ("53"). 5 + "3" → result "53" hi hoga. "5" - 3 → - string ko number mein convert kar sakta hai, result 2. "5" * 3 → conversion karke multiplication, result 15.
